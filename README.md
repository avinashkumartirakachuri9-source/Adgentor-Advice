# Advice Generator App

A simple advice generator application built with HTML, CSS, and JavaScript. The app fetches random advice from the Advice Slip API and displays it inside a responsive card UI.

## Features

* Fetches random advice from the Advice Slip API
* Generates new advice on button click
* Responsive card-based design
* Modern UI inspired by Frontend Mentor
* Built using vanilla JavaScript

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Advice Slip API

## Getting Started

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder:

```bash
cd advice-generator-app
```

3. Open `index.html` in your browser.

## API Used

Advice Slip API

https://api.adviceslip.com/advice

## How It Works

* When the page loads, a random piece of advice is fetched from the API.
* Clicking the dice button requests a new advice slip.
* The advice ID and advice text are updated dynamically using JavaScript.
